================================================================================

AGRO-IOT MONITOR

Вебпанель моніторингу та диспетчеризації мікроклімату розподілених IoT-об'єктів

================================================================================



1. ОПИС ПРОЄКТУ

--------------------------------------------------------------------------------

AgroIoT Monitor — це клієнт-серверна вебсистема для оперативного моніторингу

кліматичних показників теплиці, аналізу телеметрії у реальному часі та керування

виконавчими механізмами (полив, вентиляція).



Проєкт розроблено в межах дисципліни «Розробник фронтенду програмних систем»

(STEM-проєкт, 3 курс). Інтерфейс виконано у стриманому інженерному стилі

(SCADA/IoT-підхід) з акцентом на читабельність показників та швидкість реакції

оператора.



2. ОСНОВНИЙ ФУНКЦІОНАЛ

--------------------------------------------------------------------------------

- Мультисекторний моніторинг: окремий контроль температури повітря, вологості

  ґрунту, освітленості та рівня CO2 для кожного сектора теплиці.

- Керування вузлами (CRUD): динамічне підключення нових секторів із заданими

  пороговими значеннями та видалення існуючих.

- Фільтрація аварійних зон: швидке відображення лише тих секторів, де зафіксовано

  відхилення від норми.

- Диспетчерське керування: перемикання між автоматичним регулюванням (за

  порогами датчиків) та ручним керуванням клапанами поливу і вентиляцією.

- Серверна симуляція та тестування: фоновий генератор телеметрії на Node.js,

  кнопка тестового аварійного відхилення (перегрів/посуха) та системний журнал

  подій (Event Log).



3. ТЕХНОЛОГІЧНИЙ СТЕК ТА ЗАЛЕЖНОСТІ

--------------------------------------------------------------------------------

Frontend:

  - React (v19) — побудова компонентного інтерфейсу

  - Vite (v8) — збірка та dev-сервер

  - Tailwind CSS (v4) — утилітарна стилізація інтерфейсу

  - Recharts (v3) — візуалізація графіків телеметрії у реальному часі

  - Lucide React — векторні інженерні іконки



Backend (Симулятор та REST API):

  - Node.js — середовище виконання

  - Express (v5) — REST API сервер та фоновий цикл генерації даних

  - CORS — налаштування міждоменних запитів

  - Concurrently — одночасний запуск сервера та клієнта

5. ВСТАНОВЛЕННЯ ТА ЗАПУСК

--------------------------------------------------------------------------------

Передумови: на комп'ютері має бути встановлений Node.js (рекомендовано v20+).



Крок 1. Встановлення всіх залежностей проєкту:

  npm install



Крок 2. Запуск системи (бекенд API + фронтенд однією командою):

  npm start



Після запуску система буде доступна за адресами:

  - Вебінтерфейс (Frontend): http://localhost:5173

  - Сервер даних (Backend API): http://localhost:3001



Додаткові команди (за потреби):

  - Тільки фронтенд: npm run dev

  - Тільки бекенд:   npm run server

  - Збірка проєкту:  npm run build



6. REST API ЕНДПОІНТИ

--------------------------------------------------------------------------------

GET    /api/state                 - Отримати стан усіх секторів та журнал подій

POST   /api/sectors               - Додати новий сектор моніторингу

DELETE /api/sectors/:id           - Видалити сектор за ідентифікатором

PATCH  /api/sectors/:id/controls  - Змінити режим (Auto/Manual), полив, вентиляцію

POST   /api/sectors/:id/anomaly   - Зімітувати перегрів та падіння вологості
