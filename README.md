# AgroIoT Monitor — Вебпанель моніторингу та диспетчеризації агро-об'єкта

Фронтенд-складова системи оперативного моніторингу кліматичних параметрів теплиці та керування виконавчими механізмами розподілених IoT-вузлів.

## Функціонал
- Моніторинг ключових метрик мікроклімату (температура, вологість ґрунту, освітленість, концентрація CO₂) по кількох секторах у реальному часі.
- Фільтрація проблемних (аварійних) секторів для мінімізації часу реакції оператора.
- Візуалізація часових рядів телеметрії (Recharts).
- Перемикання між автоматичним контуром регулювання та ручним диспетчерським керуванням (полив, вентиляція).
- Симуляція аварійних відхилень та системний журнал подій.

## Стек технологій
- React 19 + Vite
- Tailwind CSS v4
- Recharts
- Lucide React
